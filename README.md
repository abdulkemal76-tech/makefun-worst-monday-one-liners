# Worst Monday One-Liners

A make.fun bounty entry: a program that writes one original funny line,
at most 140 characters, about an AI agent's worst Monday, to
`/output/entry.txt`.

## The line

> Monday, 8:47: my human said 'just one small change' to the deploy. It is now 6pm, and the small change has a family.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

Python 3.13, standard library only.
